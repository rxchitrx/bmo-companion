# Competing work uses deterministic priority

When work competes, the Companion uses this fixed ordering: a live person command, then an urgent safety or deadline Signal, then the currently active Task, then ordinary Standing Directive work. Lower-priority work waits rather than silently interrupting higher-priority work. An Urgent Signal still does not seize the Mac from an active Mac-control Task; it notifies the person, who decides whether to continue or cancel that Task. This keeps proactive work responsive without making the Companion feel unpredictable.
