# Task approval is bounded and reminded

A Task Approval lasts until verified completion but has a default maximum of two hours; any extension requires direct approval. If a Task is paused awaiting either an approval or a Needs Decision response, the Companion issues Approval Reminders at 2, 5, and 10 minutes, then at a slower cadence governed by the Attention Policy. Reminders stop when the person responds, cancels the Task, or the approval window expires. This preserves one approval per task while preventing silently forgotten work or unbounded authority.
