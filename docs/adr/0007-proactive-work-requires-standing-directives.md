# Proactive work requires standing directives

The Companion uses Ambient Awareness to observe Signals continuously, but creates autonomous Directive Tasks only through a person-defined Standing Directive with an explicit trigger, authority and response. An active Standing Directive supplies continuing Directive Authority for its explicitly named actions, so matching work does not need a new approval each time. The Companion may make Directive Proposals from repeated behavior, but cannot activate them. After a bounded number of consecutive failed or blocked Directive Tasks, the Companion applies Directive Suspension: it pauses the directive, preserves evidence, and notifies the person rather than retrying indefinitely. We chose this over either a passive Companion or unrestricted proactive action so the system can be genuinely active while its unattended behavior remains inspectable, editable and bounded.
