## What to build

Type: AFK

Deliver the first complete Companion tracer bullet. BMO owns the selected external display, accepts one general typed desktop goal, requests one Task Approval, delegates the goal to Codex without app-specific recipes, shows meaningful lifecycle state, records the outcome in the Activity Ledger, and reports success only after a Verified Outcome.

User stories covered: 1–6, 10–15, 19–20, 28, 32.

## Acceptance criteria

- [ ] The Companion Stage occupies only the selected external display and exposes idle, thinking, working, approval, speaking, and error states.
- [ ] A typed natural-language desktop goal becomes a durable Task and runs through the managed Codex app-server after one scoped approval.
- [ ] The Stage shows projected progress and ends with either a Verified Outcome or an explicit non-success state.
- [ ] The Activity Ledger records the Task, authority, meaningful actions, evidence references, and final outcome.
- [ ] Automated tests cover the end-to-end happy path and a failed/unverified outcome without relying on app-specific action scripts.
